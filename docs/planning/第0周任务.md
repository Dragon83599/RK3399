## 待完成：验收

在你自己的 PowerShell 里运行：

```powershell
.\tools\platform-tools\adb.exe version
.\tools\platform-tools\adb.exe devices
.\tools\scrcpy-win64-v4.1\scrcpy.exe
```

- [ ] `adb devices` 能看到 `List of devices attached` 以及你的设备

## 备注

- Codex 沙箱以 `CodexSandboxOffline` 账号运行，没有用户配置目录，所以沙箱里 `adb version` 会报 `Cannot mkdir '\.android'`。这是沙箱限制，不是工具坏了，你自己终端里不受影响。
- MobaXterm 可以等到第 1 周再装，串口和 SSH 阶段会用到。
