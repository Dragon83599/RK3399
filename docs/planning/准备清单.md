# RK3399 壁画音响开发准备清单

目标硬件：众云世纪 zysj1739a（RK3399，4GB + 64GB）、亚克力盒子 + 32mm 风扇。

## 1. 先确定方案

- 系统：已确定用商家代刷的 Android 9（规格书原标注 7.1/8.1，9 为定制固件）；做 App 和调试最容易。
- 功能：最小功能定为“壁纸/时钟 + 音乐播放 + 观看 B 站视频 + 开机自启”，再做语音、天气、智能家居。
- 屏幕方向：以 B 站视频为主建议横屏，先按横屏规划；后期加时钟/壁画画面时再考虑竖屏或方形屏。

## 2. 硬件清单

| 项目 | 建议 | 备注 |
| --- | --- | --- |
| 主板 | 众云世纪 zysj1739a（已有） | 向商家要接口图/原理图，确认每个接口定义 |
| 屏幕 | 第一阶段：HDMI 电脑显示屏；后期再买 MIPI 屏 | HDMI 即插即用；MIPI 屏必须和商家固件匹配，问清支持列表 |
| 功放 | 第一阶段：先确认板子音频接口；板载 2x6W 喇叭输出，家里音响需要 3.5mm 输出口 | 规格书写的是 SPEAKER OUT（LP/LN/RP/RN），未明确 3.5mm 口，需问商家 |
| 喇叭 | 两只 4Ω/8Ω 全频喇叭，按功放功率选 | 建议 4Ω 5W~10W，尺寸配合亚克力盒 |
| 电源 | DC 12V/3A（5.5x2.1mm、内正外负） | 规格书要求 12V 2A~5A；卖家送 12V/1A 仅备用 |
| 麦克风 | USB 麦克风或板载 mic（可选） | 做语音控制才需要 |

## 3. 软件与工具

向商家索要：

- Android 固件（img 或完整资料包）
- 屏幕匹配说明 / DTS / 内核源码（可选）
- 刷机教程和接口定义

电脑上安装：

- RKDevTool（瑞芯微烧录工具）
- Rockchip Driver Assistant（驱动助手）
- ADB platform-tools（`adb install`、`adb shell`）
- scrcpy（手机/板子投屏，方便看界面）
- 串口工具（MobaXterm / PuTTY）
- Android Studio（做 App 用）

## 4. 推荐开发路线

1. HDMI 接显示器，刷机、开机、联网，验证系统正常。
2. 用 HDMI 显示器验证画面；MIPI 屏等后期集成阶段再调，不亮先查背光、DTS、分辨率。
3. 用 3.5mm 线接家里现成音响，播放测试声音；功放和喇叭留到整机集成阶段。
4. 开发 App：显示壁画/时钟 + 音乐播放；推荐用 Kotlin + Android Studio，播放用 MediaPlayer 或 ExoPlayer。
5. 做成开机自启的桌面 App（Launcher/kiosk 模式），再装进亚克力盒子。
6. 整机测试：长时间播放、散热、WiFi 稳定性、声音底噪。

## 5. 常见坑

- 屏幕不亮：多数是屏幕型号和固件 DTS 不匹配，尽量买商家验证过的屏。
- 刷机变砖：刷机过程别断电；真进不了系统还能进 Maskrom 重刷。
- 功放底噪/电流声：功放最好独立供电，音频线用屏蔽线，电源共地要处理好。
- 风扇方向：进风/出风搞反等于没散热；亚克力盒要留散热孔。
- WiFi 差：天线没接好或盒内金属屏蔽。
- 亚克力盒内短路：接线裸露处用热缩管/绝缘胶带，螺丝别压线。
- 电源太小：送的 1A 带不动整机，会掉 WiFi、重启甚至伤 eMMC，正式跑机用 12V/3A。
- B 站 App 适配：手机版横屏和遥控操作不友好，优先用 HD/TV 版；HDMI 无触摸时先用鼠标操作。
