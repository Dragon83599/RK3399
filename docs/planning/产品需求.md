# 壁画音响产品需求（第一版）

## 定位

挂墙/桌面壁画音响：平时显示壁画/时钟，需要时看 B 站视频、听音乐。

- 系统：Android 9（商家代刷）
- 硬件：众云世纪 zysj1739a（RK3399，4GB + 64GB）
- 屏幕：第一阶段 HDMI 电脑显示器；后期 MIPI 屏（横屏优先）

## 第一版功能

- [ ] 开机自启进入主界面（Launcher / kiosk 模式）
- [ ] 主界面显示时钟、日期、壁画背景，带 B 站入口
- [ ] 点击 B 站入口打开哔哩哔哩 HD/TV 版，可全屏播放
- [ ] 能播放本地音乐作为备用
- [ ] WiFi 联网，断网自动重连
- [ ] 音频正常出声，无明显底噪

## 界面（默认横屏）

- 分辨率：HDMI 1080P（第一阶段）
- 布局草图（待画）：
  - 背景：壁纸/壁画
  - 左上/右上：日期、时间
  - 底部或侧边：B 站入口按钮、音量、设置
- 待定：壁纸是否轮播、是否显示天气

## 操作方式

- 第一阶段（板子到货）：USB 键盘鼠标
- 第二阶段（整机集成）：
  - [ ] 触摸屏（后期配 MIPI/LVDS 触摸屏）
  - [ ] 红外遥控器（板子有 IR 接口）
  - [ ] 蓝牙遥控器（板子有蓝牙）
- 最终选择：待定

## 音频

- 第一阶段：3.5mm 接家里音响（待确认板子是否有 3.5mm 口）
- 备选：板载 SPEAKER OUT（2x6W）接喇叭；或 USB 声卡
- 最终方案：待定

## 手机投屏方案（待选）

- [ ] 方案 A（推荐）：板子安装“哔哩哔哩 TV 版（云视听小电视）”，手机扫码登录，同 WiFi 下可投视频/当遥控器
- [ ] 方案 B：板子安装乐播投屏 / AirScreen 等接收端，手机 B 站 App 点“投屏”推流
- [ ] 方案 C：不投屏，直接在板子上登录 B 站 HD 版观看
- 最终选择：待定

## 第一版验收标准

- [ ] 插电 30 秒内自动进入主界面
- [ ] 能打开并流畅播放 B 站 1080P 视频
- [ ] 声音正常，无明显底噪
- [ ] 至少一种操作方式能完成全流程（键盘鼠标 / 触摸 / 遥控）
- [ ] 连续运行 24 小时不重启
