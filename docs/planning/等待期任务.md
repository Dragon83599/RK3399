## 每天任务表

### 第 1 天：定硬件 + 要资料

- 按上面的清单下单硬件
- 把问题清单发给商家
- 如果商家已给资料包，安装 RKDevTool 和 Driver Assistant

### 第 2 天：用手机练 adb / scrcpy

找一台安卓手机当“模拟板子”：

- 手机开启开发者模式：设置 → 关于手机 → 连点“版本号”7 次
- 开启“USB 调试”，用 USB 连电脑
- 在 PowerShell 里练习：

```powershell
.\tools\platform-tools\adb.exe devices
.\tools\platform-tools\adb.exe install 应用.apk
.\tools\platform-tools\adb.exe shell
.\tools\scrcpy-win64-v4.1\scrcpy.exe
```

- 练习 `adb push`、`adb pull`、`adb logcat`，学会看日志

### 第 3 天：学启动流程 + Linux 基础

- 用 Git Bash 练 shell：`cd`、`ls`、`cat`、`grep`、`chmod`、`ssh`
- 理解启动链路：BootROM → U-Boot → Kernel/DTB → Android
- 查资料：搜 `RK3399 启动流程`、`Rockchip U-Boot`

### 第 4 天：学屏幕和音频概念

- 屏幕：MIPI DSI、分辨率、背光、触摸、DTS 里怎么描述
- 音频：I2S、CODEC、功放、喇叭阻抗和功率
- 搜 `RK3399 DTS 屏幕点亮`、`ALSA amixer 调试`

### 第 5 天：定产品需求

- 定界面：以 B 站视频为主建议横屏；显示时钟、天气、壁纸、音乐控制、B 站入口哪些内容？
- 定音乐/视频来源：B 站 App（HD/TV 版）、本地文件、NAS、蓝牙、流媒体？
- 定操作方式：USB 键鼠 / 触摸屏 / 遥控器？
- 把需求写进 `产品需求.md`
