# RK3399 壁画音响逐周任务清单

## 项目目标

做一台能用的壁画音响：开机自动显示壁画/时钟画面，能播放音乐和观看 B 站视频，支持远程维护。本清单面向电子信息工程大四背景，主路线为 Android 固件 + Android App；业余时间约 3~6 周出第一版，含系统定制约 8~12 周。

## 硬件清单

- 众云世纪 zysj1739a（RK3399，4GB + 64GB）
- 商家代刷 Android 9 固件（板子在途）
- HDMI 电脑显示屏（第一阶段用）；MIPI 屏后期集成时再买
- 家里现成音响（3.5mm 输入，第一阶段用）；功放板 + 喇叭后期再买
- 电源（自购 DC 12V/3A；卖家送 12V/1A 仅备用）
- 亚克力盒子 + 32mm 风扇
- HDMI 线、USB 数据线、USB-TTL 串口模块、键盘鼠标

## 技术树总览

1. 板级硬件速通：接口、供电、信号通路
2. 嵌入式 Linux 与启动流程：串口、U-Boot、Kernel、用户空间
3. RK3399 平台：DTS、内核编译、屏幕/音频/GPIO 外设
4. 应用层产品化：Android App、开机自启、kiosk
5. 系统定制与量产化：裁剪、Logo、温控、日志
6. 整机集成与验收：装箱、散热、长测、故障手册

## 使用说明

- 每完成一周，把对应状态列的 `[ ]` 改为 `[x]`。
- 屏幕第一阶段用 HDMI 显示器，MIPI 屏等产品定型后再集成。
- 电源用 12V/3A 以上，卖家送的 1A 只用于最小负载测试。
- 若改走 Linux 方案，第 6 周任务替换为 ALSA/PulseAudio + MPD/mpv + Chromium kiosk + systemd 自启。
- 时间为业余时间估算，可按实际进度拉长。
